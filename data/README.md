# Datasets

| File | Used in | Rows | Description |
|---|---|---|---|
| `alkharj_accidents_2022.csv` | Chapter 6 | 365 | **Real data.** Daily road accidents in Al-Kharj, 1 Jan to 31 Dec 2022, inside and outside the city. Provided by the course instructor. |
| `students.csv` | Chapters 4, 5 | 122 | **Synthetic.** Exam grades of fictional students, with planted data problems (duplicates, missing values, sentinel values, inconsistent codes). |
| `courses.csv` | Chapter 4 | 4 | Small lookup table of programs, used to teach `merge`. |

`students.csv` and `courses.csv` are generated by `make_datasets.py` from fixed random seeds:

```bash
python data/make_datasets.py
```

## `alkharj_accidents_2022.csv` columns

Dates are written day/month/year. Every measure exists for `OutsideCity` and `WithinCity`.

| Column prefix | Meaning |
|---|---|
| `CarAccidents` | number of car accidents |
| `Deceased` | number of people killed |
| `Fatalities` | number of accidents with at least one death |
| `Injured` | number of people injured |
| `AccidentsInjuries` | number of accidents with at least one injury |

The file is published as received. Some days contain inconsistent values (for example, deaths recorded without a fatal accident); finding and handling them is part of the case study.
